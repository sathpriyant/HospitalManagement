# Hospital Management System

A beginner-level patient management project built with Python and MySQL.

## Features

- Retrieve all patient records.
- Add a new patient.
- Retrieve a patient by ID.
- Update patient details.
- Delete a patient record.

## Technologies Used

- Python
- MySQL
- `mysql-connector-python`
- `datetime` module

## Concepts Practised

- Object-oriented programming
- Classes and inheritance
- MySQL database connectivity
- SQL CRUD operations
- Parameterized SQL queries
- Exception handling

## Project Status

This project demonstrates basic patient-record management using Python and MySQL. Further improvements may include input validation, safer configuration management, and a user interface.

## Setup

1. Install Python and MySQL.
2. Create a MySQL database named `hospital_db`.
3. Create the required `patient` table with the columns used in the Python script.
4. Install the dependency:

```bash
pip install mysql-connector-python
```

5. Configure database credentials securely using environment variables.
6. Run the Python script after configuring the database.

## Note

This is a learning project, not a production-ready hospital system. Do not use real patient information in development or testing.
